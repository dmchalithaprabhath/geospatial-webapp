# Sri Lanka 7-Day Scenic Route Web Map

A modern static web page with an interactive Leaflet map and route plan for a 7-day Sri Lanka itinerary from **August 31 arrival** to **September 7 departure**.

## Included places

- Sigiriya Rock
- Pidurangala Rock sunrise
- Minneriya National Park safari
- Kandy to Ella tea train
- Waterfalls around Ella
- Colombo to Galle coastal train
- Hikkaduwa
- Galle Fort

## Files

- `index.html` - complete static website with embedded CSS/JS
- `.nojekyll` - prevents GitHub Pages/Jekyll processing issues
- `.github/workflows/pages.yml` - GitHub Pages deployment workflow

## Important note

The route lines are planned travel corridors for itinerary visualization. They are not live turn-by-turn road navigation geometries. Exact train times, seat availability, safari entry access, weather and road conditions should be verified before booking.
